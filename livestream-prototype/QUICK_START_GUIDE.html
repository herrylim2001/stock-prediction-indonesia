🚀 Quick Start (3 Langkah Mudah)

Step 1: Install Dependencies

Buka terminal/command prompt, navigate ke folder backend:

cd livestream-prototype/backend
pip install -r requirements.txt

Step 2: Start Backend Server

Jalankan server backend:

python app.py

Server akan berjalan di: http://localhost:5000

Step 3: Buka Aplikasi

Gunakan shortcut script atau buka file HTML secara manual:

📊 Open Backoffice 📱 Open Client Viewer
✓ Selesai! Sistem sudah siap digunakan untuk demo ke client.

✨ Fitur Utama

1. Backoffice Dashboard

  • Dashboard Overview: Real-time statistics (talents, livestreams, viewers, diamonds)
  • Talent Management: CRUD operations untuk manage talent
  • Livestream Monitoring: Monitor semua active livestreams
  • Analytics: Performance metrics dan top performers
  • Real-time Updates: Auto-update via WebSocket

2. Client Viewer

  • Browse Livestreams: Lihat semua livestream yang sedang LIVE
  • Watch Live: Join livestream dengan 1 click
  • Live Chat: Chat real-time dengan viewers lain
  • Like System: Send likes dengan animasi floating hearts
  • Gift System: Send virtual gifts (diamonds) ke talent
  • Viewer Count: Real-time viewer count update

3. Backend API

  • RESTful API: CRUD endpoints untuk talents & livestreams
  • WebSocket: Real-time communication via Socket.IO
  • Statistics: Platform-wide analytics
  • Auto-sync: Data sync across all clients

🎬 Demo Flow untuk Presentasi Client

Skenario 1: Admin/Management View

  1. Buka Backoffice Dashboard
  2. Tunjukkan overview statistics (total talents, active streams, viewers, revenue)
  3. Masuk ke Talent Management - edit talent, change status
  4. Masuk ke Active Livestreams - monitoring real-time
  5. Demonstrasikan real-time update (data auto-refresh)

Skenario 2: User/Viewer Experience

  1. Buka Client Viewer di browser/tab berbeda
  2. Browse livestreams yang tersedia
  3. Click card untuk join livestream
  4. Test live chat - kirim beberapa messages
  5. Click Like button - lihat floating hearts animation
  6. Click Gift - pilih gift dan send
  7. Lihat viewer count yang update real-time

Skenario 3: Multi-Viewer Simulation

  1. Buka Client Viewer di multiple tabs/browsers
  2. Join livestream yang sama dari berbagai tabs
  3. Send chat dari masing-masing tab
  4. Send likes & gifts
  5. Perhatikan semua updates sync real-time di semua tabs
  6. Check Backoffice - lihat statistics update real-time
💡 Tips: Buka Backoffice dan Client secara bersamaan dalam 2 windows/monitors untuk demonstrasi yang lebih impactful!

🔌 API Endpoints Reference

Base URL: http://localhost:5000/api

Talents:

GET /api/talents - Get all talents GET /api/talents/:id - Get talent by ID PUT /api/talents/:id - Update talent PUT /api/talents/:id/status - Update talent status

Livestreams:

GET /api/livestreams - Get active livestreams GET /api/livestreams/:id - Get livestream by ID POST /api/livestreams - Create new livestream POST /api/livestreams/:id/end - End livestream POST /api/livestreams/:id/like - Add like POST /api/livestreams/:id/gift - Send gift

Statistics:

GET /api/stats - Get platform statistics
